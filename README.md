# 🎮 Global Video Game Sales Dashboard

Interactive Power BI dashboard designed to analyze global video game sales across different regions, gaming platforms, genres, and publishers.

---

## 📌 Project Overview

This dashboard enables dynamic exploration of historical sales trends and comparative analysis through interactive filters and visual analytics.

Users can explore video game performance by:

- Region
- Platform
- Genre
- Publisher
- Year

---

## 🛠 Tools & Technologies

- Power BI
- Power Query
- Data Visualization
- Interactive Dashboard Design
- Data Modeling

---

## 📊 Dashboard Features

- KPI indicator for total copies sold
- Interactive slicers
- Regional sales analysis
- Platform comparison visuals
- Genre performance breakdown
- Detailed sales exploration table
